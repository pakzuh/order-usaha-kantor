# 🛍️ AYO!! — Portal Order & Pre-Order Internal Hub

Portal web pemesanan dan katalog pre-order terpadu untuk usaha rekan-rekan kantor di Dea Bakery.
Situs ini dirancang untuk memudahkan pemesanan tanpa risiko list chat WhatsApp tertimpa, hitungan total otomatis, kustomisasi varian (level pedas, porsi nasi, topping), salin nomor rekening instan, dan generator pesan WhatsApp siap kirim.

🌐 **Domain:** `https://ayo.rakyat.space`

## ⚡ Fitur Unggulan

- **Multi-Tenant Shop:** Pilihan toko dengan tab filter rapi.
- **Kustomisasi Lengkap:** Slider level pedas 0-6, porsi nasi normal/setengah, pilihan lauk, dan catatan khusus (*"tanpa kubis, garing"*).
- **Keranjang Belanja Per Merchant:** Pesanan otomatis dikelompokkan per penjual dengan totalan terpisah.
- **Salin Nomor Rekening 1-Klik:** Nomor rekening penjual langsung tersalin ke clipboard.
- **WhatsApp Message Generator:** Format pesanan otomatis dibuat rapi sesuai kebiasaan list di grup WA.
- **Tab Rekapitulasi Pesanan (Admin / Penjual):** Penjual dapat melihat daftar yang order dan menyalin teks rekap siap tempel ke grup WA saat *Close Order*.
